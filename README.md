# 🏭 RMG Manufacturing Dashboard | Excel Data Analytics

## 📌 Project Overview

This project is an interactive **RMG Manufacturing Dashboard** developed using Microsoft Excel to analyze garment production performance, manufacturing efficiency, rejection quantities, and factory-wise order distribution.

The dashboard transforms manufacturing data into meaningful insights through interactive visualizations and KPI indicators, helping users understand production performance and identify areas for improvement.

## 🎯 Project Objectives
- Monitor total manufacturing orders and production output.
- Analyze production target achievement.
- Track average production efficiency.
- Identify critical rejection quantities.
- Compare efficiency across fabric types and production lines.
- Analyze section-wise rejection quantities.
- Monitor factory-wise order distribution.

## 🛠️ Tools & Technologies

- Microsoft Excel
- Power Query
- Power Pivot
- PivotTables
- PivotCharts
- Excel Formulas 
- Slicers

## 📈 Key Performance Indicators (KPIs)

| KPI | Description |
|---|---|
| Total Orders | Total manufacturing orders |
| Total Output Quantity | Total units produced |
| Target Achievement % | Production output compared to target |
| Critical Reject Quantity | Total critical rejected units |
| Average Efficiency % | Average production efficiency |

## 📉 Dashboard Analysis

The dashboard includes the following visualizations:

1. **Fabric Type-wise Average Efficiency** – Compares production efficiency across Denim, Knit, and Woven fabrics.
2. **Production Line Efficiency** – Analyzes efficiency percentages across different production lines.
3. **Top 5 Rejected Categories** – Identifies the categories with the highest rejection quantities.
4. **Section-wise Rejection Analysis** – Compares rejection quantities across different manufacturing sections.
5. **Factory-wise Order Distribution** – Shows the distribution of orders across factories.

## 🎛️ Interactive Filters

The dashboard provides interactive slicers for:

- Buyer Country
- Fabric Type
- Product Category

These filters allow users to explore the data from different perspectives.

## ⚙️ Data Preparation & Analysis

The project follows these steps:

1. Imported manufacturing data into Excel.
2. Cleaned and transformed data using Power Query.
3. Appended and merged related datasets.
4. Used Group By to summarize production information.
5. Applied Unpivot to restructure data.
6. Created table relationships using Power Pivot.
7. Used DAX measures for KPI calculations.
8. Created PivotTables and PivotCharts.
9. Designed an interactive dashboard using slicers.
